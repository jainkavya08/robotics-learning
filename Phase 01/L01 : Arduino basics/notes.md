# Lesson 01 — Arduino Basics

## Objective

Understand the Arduino Uno, its microcontroller, GPIO pins, and basic program execution.

## Practical

- Built an LED circuit in Wokwi using an Arduino Uno R3.
- Connected an LED through a current-limiting resistor.
- Programmed the LED to blink every 500 milliseconds.

## Concepts Learned

- `setup()` runs once when the program starts.
- `loop()` repeats continuously.
- `pinMode()` configures a pin as input or output.
- `digitalWrite()` sets a digital output HIGH or LOW.
- Flash stores the program.
- SRAM stores temporary working data.
- EEPROM can retain data when power is removed.
- GPIO allows the microcontroller to interact with external devices.
- `analogWrite()` generates PWM on supported Arduino Uno pins.

## Architecture

The Arduino Uno R3 uses the ATmega328P microcontroller, which includes a CPU, memory, GPIO, timers, and other peripherals.

## Challenges Completed

- Made an LED blink.
- Identified the purpose of a resistor.
- Explored Flash, SRAM, and EEPROM.
- Compared `digitalWrite()` and `analogWrite()`.
